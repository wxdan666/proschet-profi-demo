# ПросчётПрофи — учёт материалов и работ на строительных объектах

Информационная система для строительно-монтажной компании: склад материалов, списание
на объекты, заявки на работы бригад, себестоимость и маржа каждого объекта, отчёты в Excel.

Программа написана для компании, где я работаю системным администратором, и заменяет
разрозненные Excel-таблицы. В репозитории — обезличенная версия: организация, объекты,
сотрудники и суммы в демо-данных вымышлены.

**Стек:** Python 3.12+, Streamlit, SQLAlchemy 2, SQLite, pandas, openpyxl, pytest.

## Возможности

- **Объекты** — реестр договоров; по каждому объекту расход материалов, стоимость работ и маржа.
- **Склад** — остатки с подсветкой позиций ниже минимума, приход со средневзвешенной ценой,
  списание с контролем остатка, возврат с объекта, журнал движения.
- **Заявки** — работы по объекту, назначение бригады, статусы.
- **Отчёты** — расход по категориям, самые затратные позиции, сводный отчёт в Excel.
- **Импорт** — перенос рабочих Excel-таблиц, составленных людьми, а не программой.
- **Сервис** — резервные копии и восстановление, доступ к разделам по PIN.

## Инженерные решения

**Атомарное изменение остатка.** Первая версия читала остаток в Python, вычитала и записывала
обратно. Тест с параллельными списаниями показал потерянное обновление: три одновременных
списания по 50 единиц при остатке 100 выдавали 150. Теперь остаток меняется одной командой
`UPDATE … SET stock = stock - :q WHERE id = :id AND stock >= :q`, а `rowcount == 0` означает
нехватку. Регрессионный тест — `tests/test_materials.py::test_concurrent_write_off_no_lost_update`.

**Журнал объясняет каждое число.** Остаток меняется только через `services/materials.py`, и каждая
операция пишет строку в `Movement`. Справочник позволяет править реквизиты позиции, но не остаток.

**Количество запросов к базе.** На 20 000 заявок страница делала 2123 запроса. После перехода на
`selectinload` и агрегаты SUM/CASE в SQL — 7 запросов, поиск быстрее в 9 раз.
Замер: `tools/bench_optimization.py`.

**Поиск по кириллице.** Встроенные `LOWER` и `LIKE` в SQLite не складывают регистр русских букв:
запрос «ОСВЕЩЕНИЕ» не находил «освещение». На каждое подключение регистрируется своя функция
`lower_ru`, весь поиск идёт через неё.

**Импорт таблиц, составленных людьми.** Шапка ищется в первых 15 строках по синонимам столбцов,
строки «Итого» и подписи отсекаются, тип файла определяется по имени. Повторный импорт
не задваивает документы.

**Резервные копии.** Копия через `sqlite3.Connection.backup` раз в день при запуске, хранится 14 штук.
Перед восстановлением — `PRAGMA integrity_check` и страховочная копия текущей базы.

**PIN с ограничением попыток.** После 5 ошибок — блокировка на 5 минут.

## Развёртывание на сервере

В `deploy/` — служба systemd и конфиг nginx для Ubuntu Server:

- программа работает от отдельного пользователя без прав администратора;
- systemd ограничивает её своей папкой: `ProtectSystem=strict`, `ProtectHome`, `NoNewPrivileges`;
- служба перезапускается после падения;
- nginx принимает запросы только из локальной сети и проксирует WebSocket, без которого
  Streamlit зависает на «Connecting».

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python launcher.py        # при первом запуске загрузит демо-данные и откроет браузер
```

macOS — двойной щелчок по `start_mac.command`, Windows — `start_windows.bat`.
PIN по умолчанию — `1234`.

## Тесты

```bash
.venv/bin/python -m pytest -q       # 56 тестов: модульные, интеграционные, параллельные списания
.venv/bin/python tools/qa_checks.py all   # проверки безопасности, нагрузки и стресса
```

Тесты работают на временной базе и не трогают рабочую.

## Структура

```
app.py              интерфейс (Streamlit): только разметка и формы
services/           вся логика: объекты, склад, заявки, отчёты, импорт, PIN, копии
database.py         модели и сессии SQLAlchemy, настройки SQLite
validators.py       проверка ввода
config.json         справочники, PIN-хеш, параметры журнала и копий
deploy/             systemd и nginx
tools/              демо-данные, замеры, QA-проверки, переносная сборка для Windows
tests/              pytest
```
